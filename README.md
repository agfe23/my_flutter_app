# my_flutter_app

Flutter 앱 프로젝트 기본 틀입니다.

## 시작하기

Flutter SDK를 설치한 뒤 프로젝트 폴더에서 아래 명령을 실행하세요.

```powershell
flutter create --platforms=android,ios .
flutter pub get
flutter run
```

`android/`, `ios/`, `lib/`, `test/` 디렉터리를 준비했습니다. Android와 iOS의 플랫폼별 생성 파일은 Flutter SDK에서 `flutter create`를 실행하면 채워집니다.
